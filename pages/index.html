Sobre o Projeto

Este projeto consiste em uma estação de monitoramento IoT utilizando um ESP32, sensores DHT11 e MQ-135.

O sistema realiza a coleta de dados ambientais e envia essas informações através do protocolo MQTT.

Os dados são recebidos pelo Dashboard Web em tempo real através de WebSockets.

Hardware Utilizado

ESP32

Microcontrolador responsável pela leitura dos sensores e conexão Wi-Fi.

DHT11

Sensor utilizado para medir temperatura e umidade.

MQ-135

Sensor utilizado para monitorar a qualidade do ar e gases.

LEDs

LEDs utilizados para indicar situações de alerta.

Resistor

Componente utilizado para limitar a corrente elétrica nos circuitos.

Protoboard

Placa utilizada para realizar conexões temporárias entre os componentes eletrônicos.

Arquitetura do Projeto

O ESP32 realiza a leitura dos sensores DHT11 e MQ-135.

Depois, os dados são enviados através da rede Wi-Fi para o broker Mosquitto utilizando o protocolo MQTT.

O Dashboard Web recebe os dados através de MQTT utilizando WebSockets.
